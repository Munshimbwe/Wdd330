UbumiHealth Enterprise Suite

Project Site Plan & Architecture Documentation

Developer: Brian Munshimbwe Kafwanka

1. Overview & Personal Motivation

UbumiHealth is an offline-first PWA built to support rural health workers, clinics, and parents dealing with acute pediatric emergencies, asthma, viral chest infections, and infectious disease screenings in disconnected environments across Zambia.

2. Target Audience

  • Parents and guardians monitoring infant and child respiratory health at night.
  • Community health workers and traveling nurses in remote rural clinics.
  • Public health coordinators requiring anonymized FHIR epidemiological data syncs.

3. Color Palette & Typography

Font Stack: System native stack for instant offline rendering.

4. ES Modules Architecture

  • main.js — Entry point & event binder
  • Store.mjs — Pub/Sub state manager
  • HealthDataService.mjs — JSON rules & OpenFDA loader
  • VitalsTracker.mjs — WHO MUAC & Respiratory triage
  • SymptomScreener.mjs — Asthma, TB, HIV & Organ risk evaluator
  • TelehealthFHIRService.mjs — HL7 FHIR v4 converter
  • AnalyticsSyncEngine.mjs — SHA-256 Web Crypto hashing & outbox
  • AccessibilityAudioService.mjs — Web Speech TTS engine
  • sw.js — Cache-First Service Worker
